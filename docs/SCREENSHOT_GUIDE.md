1. Ensure the RankCraft AI server is running:
   ```powershell
   cd C:\Users\rahul\.gemini\antigravity\scratch\rankcraft-ai
   py backend/app.py
   ```
2. Open your preferred browser (Google Chrome, Microsoft Edge, Brave, or Firefox) and navigate to:
   ```text
   http://127.0.0.1:5000/
   ```
3. Set your browser zoom to **100%** (Ctrl + 0).
4. Use standard Windows snipping shortcut: **Win + Shift + S** (or Mac: **Cmd + Shift + 4**).
