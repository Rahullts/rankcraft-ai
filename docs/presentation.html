01 / Problem & Motivation
Problem Statement & Academic Objectives
Why single-shot naive prompts fail in production SEO workflows and how systematic prompt engineering solves it.
Failure Mode 1
Unconstrained Context & Intent Drift
Single-shot prompts omit explicit persona and domain framing. Models default to generic summaries, high-perplexity marketing filler, and hallucinated search volume statistics.
Objective: Enforce Context & Role Framing to lock target domain depth.
Failure Mode 2
Structural & Boundary Non-Compliance
LLMs ignore character limits, omit essential H2/H3 hierarchy, or truncate unexpectedly. Meta descriptions exceed 160 characters, violating search engine SERP snippet bounds.
Objective: Enforce Rigid Boundary Constraints and few-shot schema conformity.
Failure Mode 3
Semantic Deliverable Fragmentation
When an article, titles, keywords, and FAQs are requested in a single prompt, outputs drift apart. Planned keywords fail to appear in headers, and FAQs repeat basic text.
Objective: Construct a 4-Stage Chained Prompt Pipeline passing typed JSON payloads.
Failure Mode 4
Subjective Quality Assessment
Evaluations traditionally rely on unquantifiable human feelings. Teams cannot scientifically measure whether a prompt modification improved SEO compliance or keyword density.
Objective: Implement a Deterministic 100-Point Rule Engine (R1–R10).

The 4-Stage Chained Prompt Engineering Pipeline
Decomposing monolithic content creation into sequential, typed transformations to eliminate context overload.
STAGE 1
SEO Strategy
POST /api/strategy
Role: Senior SEO Strategist
Inputs: Topic, Keyword, Market, Language, Audience, Intent.
Deliverables: 5 Title Options (30-60 chars), 155-160 char Meta Description, Primary / Secondary / Long-tail Keyword Sets.

STAGE 2
Content Outline
POST /api/outline
Role: Content Information Architect
Inputs: User Context + Verified Strategy Payload.

STAGE 3
Article Synthesis
POST /api/article
Role: Technical Subject Matter Writer
Inputs: Strategy (S1) + Outline (S2) + Target Length.
Deliverables: Full publication Markdown draft, H1 title, primary keyword in lead 100 words, strict section length bounds.

STAGE 4
Assets & FAQs
POST /api/faqs
Role: Search Intent Specialist
Inputs: Full Draft (S3) + Primary Keyword.
Deliverables: 3-5 conversational Q&A pairs matching intent for Google Featured Snippets and semantic search.
Targets Rubric: R7, R10
04 / Scientific Methodology
The 6 Core Prompt Engineering Techniques Implemented
Every generation stage implements specific prompt techniques designed to eliminate common LLM failure modes.
1. Role & Persona Prompting
Assigns specialized personas (Senior SEO Strategist, Technical Editor) to frame model behavioral expectations and vocabulary depth.
Eliminates: Bland generic tone & lack of authority.
2. Context & Audience Framing
Injects explicit search intent (informational/commercial), audience proficiency, market region, and language constraints into the system envelope.
Eliminates: Irrelevant summaries & intent mismatch.
3. Explicit Boundary Constraints
Enforces rigid limits: exactly 155-160 characters for meta descriptions, exactly 5 titles (30-60 chars), 4+ H2 sections, keyword density boundaries.
Eliminates: SERP truncation & unformatted text walls.
4. Few-Shot Exemplars
Provides concrete input-output examples directly in the prompt to anchor the expected JSON schema shape, tone, and technical terminology.
Eliminates: Schema non-conformity & parsing errors.
5. Structured JSON Output
Demands strict machine-parseable JSON responses with regex sanitization and markdown fence stripping for clean backend ingestion.
Eliminates: Malformed responses breaking the UI.
6. Staged Pipeline Chaining
Divides complex generation into Strategy → Outline → Article → FAQs, passing validated artifacts forward to maintain context consistency.
Eliminates: Attention dilution across long outputs.

06 / Quality Engine
Deterministic 100-Point Rubric Engine (R1–R10)
Objective algorithmic scoring measuring structural adherence, keyword distribution, and constraint compliance without subjective human bias.
Metadata Scope (40 pts)
  • R1 Title Quality (10 pts): Exactly 5 titles generated, 30–60 chars, containing primary/secondary keywords.
  • R2 Meta Description (10 pts): Rigid 155–160 character boundary check with active call-to-action.
  • R3 Keyword Sets (10 pts): Primary, 3+ secondary, 3+ long-tail keywords with zero fabricated metrics.
  • R7 FAQ Set (10 pts): 3–5 high-value FAQ pairs matching user search intent for Google Featured Snippets.
Architecture Scope (35 pts)
  • R4 Heading Structure (10 pts): Exactly 1 H1 title, minimum 4 H2 main sections, and logical H3 subsections.
  • R5 Keyword Placement (15 pts): Deterministic regex scan: keyword in H1, first 100 words, and at least one H2.
  • R6 Word-Count Accuracy (10 pts): Compares actual Markdown body count against target within ±10% margin.
Safety & Intent Scope (25 pts)
  • R8 Readability Heuristics (5 pts): Analyzes paragraph sentence length (<=5 sentences) for scannability.
  • R9 Anti-Hallucination Scan (10 pts): Scans draft for fabricated search metrics or unverified scientific claims.
  • R10 Search Intent Match (10 pts): Verifies alignment between requested intent and content execution.
